# Personas — 圆桌七人

Act 5 圆桌预演里七位读者人格的肖像源文件。运行时副本由 `app/public/avatars/` 提供（同名 PNG）。

| 文件 | 角色（中文） | persona key | 在产品里的职责 |
|---|---|---|---|
| `host.png`    | 刘看山（主编） | `host`    | 综合所有读者反馈给出主编综合意见 |
| `scholar.png` | 老学究        | `scholar` | 学院派挑刺，找硬伤、查证据 |
| `troll.png`   | 杠精本精      | `troll`   | 专业反对，每段都能找到反例 |
| `empath.png`  | 共鸣怪        | `empath`  | 情绪共鸣，破防点检测 |
| `quoter.png`  | 金句猎人      | `quoter`  | 抓金句，找截图潜质 |
| `swiper.png`  | 路人          | `swiper`  | 划走预备役，注意力警报 |
| `kol.png`     | 专业 KOL      | `kol`     | KOL 视角，行业敏锐度 |

修改这里的 PNG 后记得同步覆盖 `app/public/avatars/`，否则前端拿不到新版本。
