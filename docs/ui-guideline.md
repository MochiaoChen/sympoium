# 「会饮」UI Design Guideline v1.0

> 这是一份硬规范，目标是让任何接手开发的人都能在不再讨论审美的前提下做出风格统一的页面。

---

## 0. 设计宣言

会饮的视觉语言是**古典文人式的现代极简**。

它的参考系不是任何 AI 产品。它的参考系是 Are.na、Readwise Reader、Substack、Reflect Notes 这一脉以"严肃阅读与思考"为底色的产品。它服务的用户是写过几万字长答案的人，这群人对廉价的"科技感"已经免疫，但对良好的字距、舒适的行高、合宜的留白会产生真实的愉悦。

整个产品的视觉决策只服务一句话：**让用户进入会饮之后感到自己被认真对待**。

---

## 1. 气质参照与反参照

### 1.1 参照（看这些）

- **Are.na**：卡片、克制、用空白说话
- **Readwise Reader**：长文阅读的版式与批注美学
- **Substack Editor**：写作时的字体节奏与栏宽
- **Notion**：编辑器的克制与微交互
- **Linear**：动效的精度与卡片的呼吸感
- **Reflect Notes / Daylight Computer**：暖色极简的笔记类产品
- **泼先生（一个中文小众出版品牌）**：中文字体与版式的可借鉴度

### 1.2 反参照（远离这些）

- **任何 ChatGPT clone 的视觉范式**：气泡对话框、紫蓝渐变、"AI"badge 满天飞
- **大多数中国 AI 产品**：荧光色 CTA、不必要的玻璃拟态、生硬的"科技感"
- **过度国风**：烫金、浮华纹饰、武侠风装饰边框、夸张水墨笔触
- **聊天 IM 范式**：圆形头像、左右气泡、`Agent 1 said:` 式署名
- **B 端 SaaS 范式**：冷蓝、密集 Dashboard、12 列僵硬栅格

### 1.3 单句气质锚定

如果只能用一句话告诉开发者整个产品该长什么样：

> 它应该像一个被设计精良的文学杂志网页，恰好集成了写作工具的功能。

## 2. 色彩系统

### 2.1 设计原则

整套色彩遵循三条规则：

第一，**满屏不超过两种强色出现**。绛红用于品牌锚定，角色色用于该角色登场时的局部高亮。其余区域全部交给中性色阶。

第二，**所有角色色都使用低饱和度的传统中国色**。这是和市面 AI 产品最直接的视觉切割。

第三，**留白比颜色更重要**。当不确定要不要加颜色时，答案永远是不加。

### 2.2 基础色阶

```
背景主色   #F7F4ED   宣纸米白
背景次色   #FFFFFF   纯白
表面色     #FBF9F3   略亮米
分割线     #E8E3D8   宣纸米的边界
墨色一级   #1C1A18   主文字
墨色二级   #4A4641   次要文字
墨色三级   #8A847C   辅助文字
墨色四级   #B8B1A5   占位文字
```

`#1C1A18` 是关键选择。它不是纯黑。纯黑在米色背景上过于刺眼，这个微暖的近黑色与米白形成的对比度既舒适又有文人气。

### 2.3 品牌主色

```
绛红     #5D2A2C   主品牌色
绛红浅   #8B4548   hover / 高亮
绛红深   #3D1B1D   active / 强调
绛红纸   #F4E8E6   背景式使用
```

绛红用于：品牌 logo、关键 CTA（如"开启会饮"按钮）、当前激活的导航项、关键数据的强调。

**绝对不要**用在大面积背景或者超过单页 5% 的视觉面积。

### 2.4 七位客人的色谱

每位客人有且只有一个签名色。该色仅在角色登场时使用（角色名前的色点、角色卡片的左边框、角色发言时的小标识）。

```
望气者   #4A6B8A   远山青
测绘师   #3D5C42   山林绿
问难者   #A53A2C   朱朱
执笔者   #2B2A28   墨黑
众生*    多色      详见下方圈层
校雠     #8B6B3A   赭黄
刘看山   #0066FF   知乎蓝（IP 致敬）
```

*众生是一个集合，具体配色取决于用户选定的圈层。每个圈层 5 个读者人格，配色如下：

**科技理性圈：**
```
学霸型     #1F3A5F   深蓝
杠精型     #6B2C2E   暗红
PM 型      #4A4E5C   钢灰
原教旨型   #2F4F2F   橄榄
数据型     #5A4F2C   黄褐
```

**情感共鸣圈：**
```
共鸣型     #8B5A6B   暮霞
过来人     #5C4A3A   檀褐
心理分析   #4A5A6B   雾青
温和怀疑   #6B5C4A   烟褐
故事人     #7A4A5C   茜紫
```

**职场圈、泛知识圈、盐选叙事圈**遵循同样的"5 色低饱和"原则，色相依圈层调整。后续可补全。

### 2.5 功能色

```
成功    #4A6B42   松绿（非荧光）
警告    #A07535   秋叶橙（非荧光）
错误    #8B3A2C   绛朱
信息    #4A6B8A   远山青（与望气者同色）
```

### 2.6 热力图渐变（第五幕专用）

留存热力图的颜色不要用红蓝双极。用**冷青到暖橙的连续渐变**，5 档：

```
极冷  #C8D4E0   读者已划走（建议改）
偏冷  #DFE2DD   读者勉强读完（注意）
中性  #F2EFE7   读者无感（合格）
偏暖  #E8D5B7   读者投入（好）
极暖  #D9B88E   读者高度共鸣（金句区）
```

## 3. 字体系统

### 3.1 字体选用

**中文：**

- **正文**：思源宋体（Source Han Serif SC / Noto Serif SC），Regular / Medium / Bold
- **次要正文与 UI**：思源黑体（Source Han Sans SC / Noto Sans SC），Regular / Medium
- **强调**：思源宋体 Bold 或 Heavy

会饮的中文正文用宋体而不用黑体，这是和绝大多数现代产品的关键分野。宋体的横细竖粗、有衬线、有起笔收笔的笔锋，是会饮"古典文人式"气质的字面来源。读起来比黑体慢一点点，恰好是这个产品希望的阅读节奏。

UI 元素（按钮、菜单、表单、tooltip）用思源黑体，保持系统操作的清晰度。

**西文：**

- **正文**：Lora，与思源宋体形成合适的中西文搭配
- **次要**：IBM Plex Sans 或 Inter（如果开发偏好系统字体，Inter 可以接受，但绝不用 Arial 或 Roboto）
- **数字与代码**：JetBrains Mono

### 3.2 字号阶梯（8pt scale，桌面端）

```
display    44px   1.2 line-height   宋体 Bold     仅用于首页 hero 与会饮开始页
h1         32px   1.3                宋体 Bold     幕标题
h2         24px   1.4                宋体 Medium   段落标题
h3         20px   1.5                宋体 Medium   卡片标题
body-lg    18px   1.75               宋体 Regular  长文阅读专用
body       16px   1.7                宋体 Regular  默认正文
ui         14px   1.5                黑体 Regular  UI 元素
caption    13px   1.5                黑体 Regular  辅助说明
micro      12px   1.4                黑体 Regular  标签、metadata
```

`body-lg` 在第五幕和第六幕的草稿展示中使用。长文阅读用 18px 比 16px 体感差异巨大，是这个产品独特感的来源之一。

### 3.3 字重使用规则

中文宋体只用三个字重：Regular、Medium、Bold。**严禁 Light**，因为思源宋体的 Light 在屏幕上发虚，破坏严肃感。

### 3.4 字距与行距

中文字距全局 `letter-spacing: 0.02em`。这是宋体在屏幕上的最佳呼吸量。

正文行距 1.7 到 1.75。这比绝大多数产品的 1.5 显著宽，是长文阅读的关键。

中文与西文混排自动加 4px 缓冲，可用 `:lang(zh) + :lang(en)` 或者直接在 React 组件层处理。

## 4. 间距与栅格

### 4.1 间距 token（4pt scale）

```
spacing-1   4px
spacing-2   8px
spacing-3   12px
spacing-4   16px
spacing-6   24px
spacing-8   32px
spacing-12  48px
spacing-16  64px
spacing-24  96px
spacing-32  128px
```

### 4.2 内容最大宽度

```
prose-narrow   600px   长文阅读栏（第五幕草稿展示）
prose-default  720px   正文区
prose-wide     960px   带侧栏的内容区
canvas         1200px  星图与圆桌可视化
```

长文阅读栏 600px 是经过验证的中文最舒适阅读宽度。**不要因为屏幕宽就拉宽**。

### 4.3 栅格

不用 12 列僵硬栅格。用 CSS Grid 或 Flexbox 按场景设计。

主框架是简单的三段式：左侧导航（240px）、主内容区（弹性）、右侧辅助区（按需 320 到 400px）。

第五幕的特殊布局：草稿展示区（680px 固定）+ 弹幕区（按需弹出，宽度可变）。

## 5. 核心组件

### 5.1 角色徽标（Agent Badge）

这是会饮独有的组件。整个产品里凡是某位客人"说话"的地方，发言前都带一个角色徽标。

```
[●测绘师]
```

具体规格：

- 一个 8x8 的色点（该角色签名色填充）
- 紧跟角色名（思源宋体 Medium，14px，墨色一级）
- 整体高度 20px
- 色点与名字之间 6px 间距
- 名字下方可选 caption（黑体 Regular，12px，墨色三级），用于职责说明，比如"答场分析师"

**不要做圆形头像。** 不要用 emoji。色点就够了。这是会饮区别于聊天 UI 的关键视觉决策。

### 5.2 卡片

会饮的卡片是产品视觉的基本砌块。规格：

- 圆角 4px（不是 8px 或 12px。文人气质要求克制）
- 背景 `#FBF9F3`（表面色）或纯白
- 边框 1px solid `#E8E3D8`
- padding 24px（紧凑场景 16px）
- 阴影：默认无阴影。hover 时加一个极淡的 `0 2px 8px rgba(28, 26, 24, 0.04)`

**不要做玻璃拟态、不要 backdrop-filter、不要花式渐变边框。** 卡片就是卡片。

### 5.3 按钮

主按钮：

```
背景    绛红 #5D2A2C
文字    白 #FFFFFF
字体    思源黑体 Medium 14px
padding 10px 20px
圆角    4px
hover   背景变绛红浅 #8B4548
```

次按钮（边框型）：

```
背景    透明
边框    1px solid 墨色二级 #4A4641
文字    墨色一级 #1C1A18
hover   背景 #F7F4ED，边框变绛红
```

文字按钮：

```
文字    墨色二级，带 1px 下划线（border-bottom 而非 text-decoration）
hover   文字变绛红，下划线也变绛红
```

### 5.4 段落容器（Paragraph Treatment）

这是会饮的核心特殊组件。在第五幕，用户的草稿按段落展示，每段是一个独立的容器，承载热力图背景与弹幕锚点。

规格：

- 容器宽度 600px（长文阅读宽）
- 段落之间 32px 间距
- 默认背景 `#FBF9F3`，左侧 3px 留白
- 热力图状态：背景色按 2.6 节的 5 档渐变填充，左侧 3px 变成对应温度色的 100% 饱和版本作为视觉锚点
- 段落右侧 60px 处可挂载弹幕锚点（一个 8x8 的色点，代表有 N 条弹幕指向这一段）

段落 hover 时整个容器向右浮动 4px，弹幕从右侧自动展开。

### 5.5 弹幕卡片（Bullet Comment Card）

弹幕从屏幕右侧飞入，是第五幕的视觉主角。规格：

- 宽度 280px，圆角 4px
- 背景 `#FFFFFF`，边框 1px solid 该读者人格的签名色（饱和度降低到 50%）
- 顶部一行：角色徽标
- 中间：弹幕内容，宋体 Regular 14px，最多 3 行
- 底部：可选的"指向第 N 段"小标签

入场动效：从右侧 40px 外淡入，spring physics，stiffness 200 damping 25。

**不要做聊天气泡的尖角**。卡片就是卡片。

### 5.6 输入区

用户粘贴草稿、写素材、写问题等的输入区遵循统一规格：

- 字体 思源宋体 Regular 16px
- 行高 1.7
- padding 16px
- 背景 `#FBF9F3`
- 边框 1px solid `#E8E3D8`
- focus 时边框变绛红，无 box-shadow

placeholder 文案要写得有人格。比如第一幕选定主题的输入框 placeholder 不应该是"请输入...",应该是"今天想写点什么"或者"被什么击中了"。

## 6. 七幕页面架构

每一幕的页面布局都不同，但共享一条**横向时间轴**作为导航。

### 6.1 全局框架

```
┌─────────────────────────────────────────────────────────┐
│ [会饮 logo]                              [用户]  [设置] │  顶栏 64px
├─────────────────────────────────────────────────────────┤
│  ●─────●─────○─────○─────○─────○─────○                  │  时间轴 48px
│  起意  择题  寻位  下笔  预演  重审  出酒                  │
├─────────────────────────────────────────────────────────┤
│                                                          │
│                  主内容区（按幕变化）                       │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

时间轴用横向小圆点表示当前进度。已完成的幕用绛红实心圆，当前幕用绛红空心圆带 2px 边框，未到达的幕用墨色三级实心圆。圆点之间用 1px 实线连接。

### 6.2 第一幕：起意

布局类型：**信息流**。

```
┌─────────────────────────────────┐
│ "今天值得写什么"                  │  宋体 32px
│ 望气者已经替你看过外面的世界        │  灰 14px caption
├─────────────────────────────────┤
│                                  │
│  ● 望气者                         │
│  ┌──────────────────────────┐    │
│  │ 推送卡片 1                │    │
│  └──────────────────────────┘    │
│                                  │
│  ┌──────────────────────────┐    │
│  │ 推送卡片 2                │    │
│  └──────────────────────────┘    │
│                                  │
└─────────────────────────────────┘
```

每张推送卡片包含：交叉判断的理由（一两句话）、对应的具体问题、"展开看看"按钮。卡片之间留 24px。

### 6.3 第二幕：择题

布局类型：**列表**。

如果用户从第一幕已经选定了具体问题，跳过。否则用一个紧凑的问题列表，每行展示问题标题、回答数、饱和度评分（一个 5 格小条形，颜色从松绿到绛红）。

### 6.4 第三幕：寻位（核心视觉一）

布局类型：**双栏，左侧星图，右侧间隙清单**。

```
┌───────────────────────┬──────────────────┐
│                        │ ● 测绘师          │
│   答场星图              │                  │
│   （d3 force-layout）   │ 可写间隙清单       │
│                        │ ┌──────────────┐ │
│   ✦  ✦         ✦       │ │ 间隙 1 [金]   │ │
│      ✦   ✦             │ │ 间隙 2 [可疑] │ │
│  ✦       ✦  ✦          │ │ 间隙 3 [金]   │ │
│      ⊕  ⊕              │ └──────────────┘ │
│                        │                  │
│  ⊕  暗淡轮廓 = 未言位置  │ ● 问难者          │
│                        │ 选中间隙后展开审判 │
└───────────────────────┴──────────────────┘
```

星图区域占 65% 宽度，间隙清单占 35%。

星图视觉规格：

- 背景 `#1C1A18`（墨黑），制造星图感
- 已言说节点：直径 4 到 12px（按热度），填充米白，亮度 80%
- 已言说连接：1px solid 米白，透明度 30%
- 未言说节点：直径 16 到 24px，无填充，1.5px 虚线边框（米白透明度 50%）
- 标签：当 hover 节点时，节点上方浮现该论点的一行文字描述

这是 demo 的视觉锚点，值得在动画上下功夫。页面进入时节点应该按"星辰浮现"的效果错时间淡入。

### 6.5 第四幕：下笔

布局类型：**编辑器加侧栏**。

```
┌──────────────────────────┬──────────────────┐
│                           │ ● 执笔者          │
│   你的草稿                 │                  │
│   （这是编辑器，user 在这    │ 骨架               │
│    里写或粘贴）             │ 1. 标题候选         │
│                           │ 2. 论点序列         │
│                           │ 3. 反对预防策略     │
│                           │                  │
└──────────────────────────┴──────────────────┘
```

编辑器宽 720px，骨架侧栏 320px。编辑器使用 Tiptap 或 Lexical，禁用所有花哨格式化（没有颜色、没有 emoji、没有 highlight），保留段落、加粗、引用、列表四种基础格式即可。

### 6.6 第五幕：预演（核心视觉二）

布局类型：**长文阅读栏加右侧弹幕区**。

```
┌────────────────────┬───────────────┐
│                     │               │
│  你的草稿            │   弹幕区        │
│  按段落渲染           │  ● 学霸: ...   │
│  每段背景按温度上色    │  ● 杠精: ...   │
│                     │  ● 金句: ...   │
│  [段 1] 暖色背景       │               │
│  [段 2] 中性背景       │   弹幕从右      │
│  [段 3] 冷色背景       │   侧飞入        │
│  [段 4] 极冷背景       │               │
│                     │               │
└────────────────────┴───────────────┘
                                       
        ↓ 全文读完后
                                       
┌─────────────────────────────────────┐
│   点赞率 ████░░ 67%                   │
│   评论率 ███░░░ 42%                   │
│   收藏率 █████░ 78%                   │
│   划走率 ██░░░░ 23%                   │
└─────────────────────────────────────┘
```

草稿展示宽 600px，弹幕区宽 320px。

弹幕入场是 demo 的关键时刻。当用户按下"开始预演"按钮，应该有 2 秒的"读者落座"动效（弹幕区出现 5 到 7 个角色徽标淡入），然后弹幕开始按段落顺序错时间飞入。同一时间最多有 3 条弹幕同时存在，第 4 条进来时第 1 条向上推出。

百分比条形条用 `framer-motion` 的 `animate={{ width: ... }}` 实现，duration 1.2s，ease `[0.22, 0.61, 0.36, 1]`。

### 6.7 第六幕：重审（核心视觉三）

布局类型：**圆桌**。

```
                      ● 刘看山
                      （主编/主持）
                     ╱           ╲
                    ╱             ╲
            ● 测绘师                ● 校雠
                   ╱               ╲
                  ╱                 ╲
            ● 望气者     [你的草稿]    ● 问难者
                  ╲                 ╱
                   ╲               ╱
            ● 学霸                  ● 共鸣型
                    ╲             ╱
                     ╲           ╱
                      ● 金句猎人
```

七位客人围坐成一个椭圆。中心区是你的草稿缩略图（可点击放大）。

发言机制：

- 默认状态，所有徽标安静地停在自己的位置，签名色处于 30% 饱和度
- 轮到某位客人发言时，该徽标饱和度升到 100%，并向中心方向浮动 16px
- 该客人的发言以一张大卡片（宽 480px，padding 32px）从徽标位置浮出，浮在草稿之上
- 发言完毕，卡片折叠回徽标位置，徽标退回原位，下一位接力

整个圆桌的发言序列大约 90 秒。最后刘看山的综合卡片永久停在草稿中央，列出三条修改建议。

视觉技术实现：CSS Grid 或者 absolute positioning + transform。建议每个徽标用 absolute 定位绑定一个固定坐标，发言时用 framer-motion 改变 scale 和 position。

### 6.8 第七幕：出酒

布局类型：**预览加发布**。

```
┌─────────────────────────────────────┐
│   最终预览                            │
│   ┌─────────────────────────────┐   │
│   │                              │   │
│   │  你的答案最终版                │   │
│   │  （干净的长文阅读视图）         │   │
│   │                              │   │
│   └─────────────────────────────┘   │
│                                      │
│   发布到知乎圈子   [按钮]              │
│   复制全文        [按钮]              │
└─────────────────────────────────────┘
```

预览区用 `prose-narrow`（600px）宽度，宋体 Regular 18px，纯净的长文阅读视图。

发布后展示一个轻量的"圈子内实时反馈"面板，展示前几条点赞和评论。

## 7. 标志性视觉模式

### 7.1 答场星图

已在 6.4 节描述。

补充：星图节点可以用一种"墨点散开"的效果做强化。每个节点周围 2px 范围内有一层淡淡的发光（box-shadow），亮度按节点热度决定。这一层光环让星图看起来像真的有"温度"。

### 7.2 留存热力图

已在 6.6 节描述。

补充：热力图不要用红绿双极。用 2.6 节的青到橙渐变。原因是红绿对色盲不友好，且青到橙在中文阅读视觉里更接近"凉热"的感受，而非"对错"的判断。

### 7.3 弹幕涌入

已在 6.6 节描述。

补充：弹幕的飞入轨迹应该有轻微的弧度而非直线。从右侧屏外 40px 处，沿一个 cubic-bezier 路径滑入到最终位置，并轻微 overshoot 后回弹。

### 7.4 圆桌会议

已在 6.7 节描述。

补充：当某位客人正在发言时，其他六位徽标可以轻微"前倾"（scale 1.02, translateY -2px），制造"大家都在认真听"的视觉效果。

### 7.5 时间轴

全局顶部的时间轴是产品的视觉骨架。它必须：

- 永远可见
- 状态变化有动画（实心圆点的填充用 framer-motion 的 scale spring）
- 可点击跳转到任意已完成的幕

## 8. 微交互与动效

### 8.1 总原则

所有动效服从三条规则：

第一，**动效不超过 400ms**。除非是大型场景转换（如圆桌出场），其他都在 200 到 300ms 之间。

第二，**默认 ease 是 `[0.22, 0.61, 0.36, 1]`**，这是一个比 ease-out 略锐利的曲线，给系统一种"利落"感。

第三，**Spring 仅用于"出场"动效**。物件首次进入屏幕用 spring，stiffness 200 到 300，damping 20 到 30。这给入场带来生命感。

### 8.2 关键场景

- **页面切换（幕之间）**：水平 24px 位移加 200ms 淡入。模拟"翻一页"的感觉，但不能太重。
- **弹幕飞入**：见 7.3。
- **百分比条形**：1.2s 缓动到目标宽度。
- **圆桌徽标发言切换**：徽标本体 200ms 缓动，发言卡片 spring 出场 400ms。
- **按钮 hover**：背景色 150ms 缓动。
- **卡片 hover**：阴影出现 200ms。

### 8.3 反模式

不要做这些：

- 自动循环的呼吸光效（除非是 loading 状态）
- 鼠标尾迹
- 滚动视差（除非是 landing page）
- "AI 思考中"的转圈圈动画（用打字机或者跳动的省略号替代）

## 9. 响应式策略

会饮是桌面优先的产品。它的核心使用场景是用户坐在电脑前完成一篇长答案的写作。

但产品必须在移动端可读、可浏览（虽然不一定可写）。响应式断点：

```
xs    < 640px    移动端，只读视图，七幕折叠为可滑动卡片
sm    640px+     大屏移动 / 小平板，单栏布局
md    768px+     平板，开始展示侧栏
lg    1024px+    小桌面，完整布局
xl    1280px+    桌面，最佳体验
2xl   1536px+    大屏桌面，画布扩展（星图、圆桌可更宽）
```

移动端隐藏的功能：第四幕的写作（移动端不适合写长文）、第七幕的发布（保留预览）。其他幕都做可读的简化版本。

## 10. 暗黑模式

会饮是一个**强烈推荐浅色为默认**的产品。米色背景与宋体的搭配是产品身份的核心。

但仍然提供暗黑模式作为可选项，原则：

- 背景从 `#F7F4ED` 切换到 `#1C1A18`（墨色一级反过来当背景）
- 文字从墨色切到 `#E5E0D5`（米色）
- 表面色从 `#FBF9F3` 切到 `#262420`
- 绛红主品牌色保持 `#5D2A2C` 不变（在暗背景上依然能看清）
- 七位客人的色谱在暗模式下亮度全部提升 15%

第三幕的星图本身就是深色背景，无需切换。

## 11. 不做什么（Anti-pattern 总表）

把这一节贴给 Cursor，让它显式避开：

1. 不要用 Inter、Roboto、Arial 作为中文产品的主字体
2. 不要用紫色或紫蓝渐变作为品牌色
3. 不要做"AI"字样的 badge 或贴纸
4. 不要做聊天气泡 + 圆形头像的对话 UI
5. 不要做玻璃拟态（backdrop-filter blur）
6. 不要在长文区域用纯白背景（一律 `#FBF9F3` 或 `#F7F4ED`）
7. 不要用 emoji 作为功能图标
8. 不要做"霓虹光晕"的 CTA 按钮
9. 不要把热力图做成红绿双极
10. 不要用任何 12 列僵硬栅格
11. 不要在动效里出现 bounce（除了 spring 的自然 overshoot）
12. 不要做 dark mode default（除非用户主动切换）
13. 不要在角色徽标里用真实人脸或卡通形象
14. 不要把刘看山做成知乎官方那个 3D 卡通版本（太重，与气质冲突），用极简化的几何剪影
